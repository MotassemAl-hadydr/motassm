## 📋 نبذة عن المشروع

**نظام إدارة الكهرباء** هو تطبيق تم تطويره باستخدام Flutter بهدف تسهيل وتنظيم إدارة المشتركين والعدادات وقراءات استهلاك الكهرباء والفواتير داخل نظام واحد.

يوفر التطبيق واجهة عربية سهلة الاستخدام، مع نظام لإدارة الموظفين والصلاحيات، بحيث يستطيع **المدير الرئيسي** التحكم في المستخدمين وتحديد الدور والصلاحيات المناسبة لكل موظف.

يعتمد المشروع على **Firebase Authentication** لإدارة تسجيل الدخول والمصادقة، وعلى **Cloud Firestore** لتخزين وإدارة البيانات.

> **ملاحظة:** المشروع لا يستخدم REST API حاليًا، وإنما يعتمد على Firebase وCloud Firestore للتعامل مع البيانات.
